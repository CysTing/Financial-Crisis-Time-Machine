Title: Build Financial Time Machine causal portfolio simulator

Description:

Adds a five-page Streamlit application for historical crisis replay and retrospective strategy comparison. The shared Python engine queues decisions for next-session-close execution, sizes long-only allocations against post-cost equity, reconciles cash/P&L, and exposes date-restricted Survival views and exports.

Includes three scenarios, seven ETFs plus cash, six systematic strategies, matched SPY/60-40 benchmarks, sourced disclosure-aware events, risk analytics, an educational survival score, CSV/HTML reports, and an explicit offline synthetic demonstration. Genuine downloads are validated against exchange sessions and cached separately; no market observations are bundled.

Adds a dated decision journal, factual portfolio-move pulses with optional reduced-motion-aware emphasis, and a computed crisis debrief. Mission configuration changes invalidate old preflight results; allocation drafts persist across navigation; benchmark selection and chart filtering do not alter the replay clock or holdings.

Mission Control includes an explicitly synthetic one-click crisis showcase. Replay and report views expose eight computed integrity checks, an isolated corruption drill, and a downloadable run passport with canonical dataset fingerprints. The responsive landing page explains the execution model and keeps the offline demonstration easy to discover.

Final reliability fixes bound research capital, validate cached provenance before reuse, preserve formula-like CSV notes as literal text, and propagate launcher exit codes. Lifecycle tests cover reporting, download reruns, returning to Mission Control, and new attempts.

Validation: see docs/ACCEPTANCE.md for the exact local test/browser/provider results. GitHub Actions is configured; remote CI and live deployment require publication and have not been claimed.
